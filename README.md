# 経産省資金フロー

経済産業省とNEDO等の所管法人から、どの企業へ、どの制度を通じて、いくら流れたかを検索する非公式プロトタイプです。契約額・交付決定額・確定額・支払済額を同一視せず、金額の段階と原典URLを保持します。

## 現在の収録範囲

- NEDO「随意契約の公表：委託契約」の月別CSVに掲載された企業契約
- GビズINFOダッシュボードの経産省グループ補助金・調達件数
- GビズINFO REST API v2による、収録法人の経産省系補助金・調達明細（APIトークン設定時）
- 検証用のGビズINFO／ものづくり補助金レコード

実支出額が公開されていない場合は `0` ではなく「未公表」と表示します。現在はMVPのため、経産省本省や全所管法人の明細を網羅していません。

## 自動更新

`.github/workflows/update-data.yml` が毎日6時30分（日本時間）に動きます。

1. NEDOの契約公表ページから月別CSVリンクを自動発見
2. Shift_JISのCSVを読み、法人番号・契約日・契約額を正規化
3. 企業契約だけを抽出し、重複を安定IDで除外
4. GビズINFOの経産省グループ件数を照合
5. APIトークンがあれば、収録済み法人の補助金・調達明細をAPI v2で更新
6. 本番ビルドが成功した場合だけ変更をコミット

取得に失敗したソースは、前回の明細を消さずに状態を「要確認」に変えます。取得先は `data/source-registry.json` で管理しています。

### GビズINFO APIの接続

GビズINFOの利用申請後、GitHubリポジトリの `Settings` → `Secrets and variables` → `Actions` で、Repository secret `GBIZINFO_API_TOKEN` に発行されたトークンを登録します。トークンはコードやログへ出力しません。未設定時はAPI明細だけをスキップし、NEDO CSVと公開ダッシュボードの更新は継続します。

GビズINFOの補助金情報は「活動金額」として提供され、交付決定・確定・実支出の段階が一律には判別できないため、画面では「補助金掲載額」と表示します。

公開サイトは `main` ブランチの `data/funding-data.json` をGitHub Rawから取得し、Actionsの更新コミットへ再デプロイなしで追随します。GitHubから取得できない場合は、最後にビルドへ内蔵されたデータを表示します。この方式を使うにはリポジトリをPublicにしてください。Privateで運用する場合は、更新後にホスティングを再デプロイする構成へ変更する必要があります。

## ローカル実行

Node.js 22.13以上が必要です。

```bash
npm ci
npm run update:data
npm run dev
```

ビルド検証:

```bash
npm run build
```

## データ設計上の注意

- 上流の基金造成額と下流の企業契約額を単純合算しません。
- 同じ企業は13桁の法人番号を主キーとして扱います。
- 採択、交付決定、契約、額の確定、支払済を別の `stage` として保存します。
- 共同事業、変更契約、企業名の旧称・表記ゆれは今後の名寄せ対象です。
- 公開情報を再構成したもので、経済産業省・NEDOの公式サイトではありません。
