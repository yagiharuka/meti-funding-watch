# 事業者等への交付金額(経産省)

公開サイト: https://yagiharuka.github.io/meti-funding-watch/

経済産業省と所管法人から、どの企業・大学・一般法人・自治体等へ、どの制度を通じて、いくら流れたかを検索する非公式プロトタイプです。

公開サイトは、METI内へ **SharePoint Online＋Power Apps＋Dataverse＋Power Automate** で移植した場合の完成イメージも兼ねています。庁内版はGitHubへ接続せず、GビズINFOを日次差分更新、行政事業レビューシートを年1回更新する想定です。

詳細な移植手順：[`docs/METI_POWER_APPS_MIGRATION_GUIDE.md`](docs/METI_POWER_APPS_MIGRATION_GUIDE.md)

## 現在の収録範囲

- 行政事業レビュー公式CSVの2024・2025年度シートに含まれる経産省分（原則2023・2024年度支出。事業、予算・執行、支出先、支出ブロックのつながり）
- 支出ブロックの接続から「実施機関・中間受取先」と「公表経路上の受取先」を分離した支出先明細
- GビズINFOの日次全件CSVから抽出した、経産省・地方経済産業局・所管法人の補助金／調達明細（トークン設定時）

NEDO独自の月次契約CSVは初期移植版の表示・更新対象から外しています。GビズINFOに掲載されたNEDOのレコードはGビズINFO系列として表示します。

実支出額や活動金額が公開されていない場合は `0` ではなく「未公表」と表示します。行政事業レビューに掲載された支出先は、法人番号が空欄でも掲載名のまま収録します。

## 自動更新

`.github/workflows/update-data.yml` が毎日6時30分（日本時間）に動きます。

1. 行政事業レビューの公開年度APIから公式CSVを取得できる全年度を判定
2. 各年度の公式ZIP/CSVを取得し、経産省の事業・予算執行・支出先・支出経路を結合
3. 支出ブロックのグラフをたどり、上流の実施機関と公表経路上の受取先を分類
4. GビズINFOの経産省グループ件数を照合し、APIトークンがあれば補助金・調達の全件CSVを取得
5. 各系列の重複を安定IDで除外し、本番ビルドが成功した場合だけ変更をコミット

取得に失敗したソースは、前回の明細を消さずに状態を「要確認」に変えます。取得先は `data/source-registry.json` で管理しています。

### GビズINFO APIの接続

GビズINFOの利用申請後、GitHubリポジトリの `Settings` → `Secrets and variables` → `Actions` で、Repository secret `GBIZINFO_API_TOKEN` に発行されたトークンを登録します。トークンはコードやログへ出力しません。未設定時は全件CSVをスキップし、レビューシートの更新確認は継続します。

GビズINFOの補助金情報は「活動金額」として提供され、交付決定・確定・実支出の段階が一律には判別できないため、画面では「補助金掲載額」と表示します。

公開サイトは年度・系列別に分割したJSONを必要なときだけ読み込みます。全件を一度にHTMLへ描画せず、検索結果を100件ずつページ分割します。取得できない場合は、読み込み中のままにせず状態を明示します。

## 庁内移植版の更新方式

GitHub版の自動更新方式と、Power Platform上の庁内版の方式は分けます。

| データ | 初回 | 通常更新 |
| --- | --- | --- |
| GビズINFO | 全件CSVから経産省系だけ取込 | 期間指定APIで毎日差分取込 |
| 行政事業レビュー | 収録可能な年度を一括取込 | 新年度公表後に年1回追加 |
| NEDO独自CSV | 取り込まない | 取り込まない |

庁内版の具体的なテーブル定義、Power Appsの画面構成、Power AutomateのAPI設定、SharePointへの埋込手順は[移植手順書](docs/METI_POWER_APPS_MIGRATION_GUIDE.md)に記載しています。

## ローカル実行

Node.js 22.13以上が必要です。

```bash
npm ci
npm run update:data
npm run dev
```

ビルド検証:

```bash
npm run build
```

## データ設計上の注意

- 上流の基金・運営費交付等と下流の受取先額を単純合算しません。
- 行政事業レビューの支出先額、事業執行額、GビズINFO等の契約・補助金掲載額を別系列として表示します。
- 異なる系列を比べる場合は共通して収録されている同一年度に限定し、期間の違う全期間総額は横並びにしません。
- 同じ受取先は13桁の法人番号を主キーとして扱います。
- 採択、交付決定、契約、額の確定、支払済を別の `stage` として保存します。
- 2024・2025年度レビューシートの支出先情報は、原則として2023・2024年度の支出として表示します。
- RSシステムで検索できる2021〜2023年度シートは移行データで、支出先詳細・支出経路が不足するため全件集計には含めません。
- レビューシートの予算・執行額はシート単純合計であり、同一予算事業の重複を含む可能性があります。
- 共同事業、変更契約、受取先名の旧称・表記ゆれは今後の名寄せ対象です。
- 公開情報を再構成したもので、経済産業省の公式サイトではありません。

行政事業レビューのデータは[行政事業レビュー見える化サイト](https://rssystem.go.jp/download-csv)から取得し、当プロジェクトで編集・加工しています。
