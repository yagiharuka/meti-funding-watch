# 経産省関係の調達（委託を含む）・補助金情報

公開サイト: https://yagiharuka.github.io/meti-funding-watch/

GビズINFOに掲載された「調達」（委託を含む）と「補助金」の情報のうち、公表組織が次のいずれかに該当する行を検索する非公式サイトです。

- 経済産業省（地方経済産業局を含む）
- 資源エネルギー庁
- 中小企業庁
- 特許庁
- 情報処理推進機構（IPA）
- 新エネルギー・産業技術総合開発機構（NEDO）

法人等の名称（全件CSVの「商号または名称」）と13桁の法人番号で検索できます。各府省庁から提供され、法人番号が付与されてGビズINFOに掲載された情報だけが対象であり、網羅性や支払実績を示すものではありません。

別タブの「契約結果・交付決定」では、公式資料に掲載された交付先・契約相手、法人番号、事業名、備考を明細検索できます。現在は2025年度の中小企業庁3冊と特許庁4冊の公式XLSXだけを収録し、掲載行数は検証済みmanifestから表示します。中小企業庁の随意契約、特許庁の委託契約・公共工事、他の11執行機関・他年度は未収録です。26の公式入口も併記し、未収録資料を収録済みとは数えません。契約額欄の掲載値、交付決定額欄の掲載値、GビズINFO掲載値は相互に合算しません。

## 表示値の意味

- 調達の金額はGビズINFOの「落札価格／活動金額」です。単価や売払いが含まれる場合があります。
- 補助金の金額はGビズINFOの「活動金額」です。交付決定、変更、確定など異なる状態の掲載が混在します。
- そのため金額は足し上げず、掲載行ごとに表示します。
- `0円`、負数、空欄を別々に保持します。空欄だけを「金額の記載なし」と表示します。
- 年度は認定日または受注日の4月始まりで当サイトが算出します。日付がない行は「年度不明」です。
- 公表組織から上流の資金経路はGビズINFOの項目から判定できないため、推定経路は作成しません。

## 自動更新

`.github/workflows/update-data.yml` が毎日6時30分（日本時間）に動きます。

1. 中小企業庁・特許庁の収録対象XLSXと、GビズINFOの補助金・調達の全件CSVを再取得
2. 公式XLSXは見出し・行数・原本SHA・前回行の継続性を確認し、GビズINFOは対象公表組織の行を抽出
3. 全件CSVの対象行数と取込行数が、補助金・調達それぞれで一致することを確認
4. GビズINFO公式ダッシュボードとの差は、別スナップショットの参考値として記録
5. 両系列と公開ファイルのSHA・行数・ID集合を検証し、テスト済みの同じ成果物だけをGitHub Pagesへ公開

全件CSVの対象行と取込行が1行でも一致しない場合は公開しません。公式ダッシュボードと全件CSVは更新時点や集計条件が異なる可能性があるため、両者の差は「取込漏れ」とせず別に表示します。

Repository secret `GBIZINFO_API_TOKEN` がない場合や取得に失敗した場合は、前回の明細と最終取込日時を保持し、状態を「要確認」にします。公式画面の確認時刻だけで明細の鮮度を更新することはありません。

日次実行または手動更新で安全検査に失敗した場合は公開処理そのものを停止します。画面修正を含む `main` へのpushでは、候補データが安全検査で停止しても、直前の検証済みデータに対して全テストを通した画面だけを公開できます。候補データで前回キーの欠落・内容変更、区分別件数差の拡大、異常な急増、未承認の公表組織名を検出した場合、新しい明細へは置き換えません。

公開用データは年度別の `commitments-*.json` とmanifestだけです。行政事業レビュー由来のデータは現行サイトの取込・表示・公開対象に含めません。

## ローカル実行

Node.js 22.13以上が必要です。

```bash
npm ci
npm run update:official
npm run update:data
npm test
npm run dev
```

公開情報を再構成したもので、経済産業省およびGビズINFOの公式サイトではありません。原データの定義・免責事項は[GビズINFO](https://info.gbiz.go.jp/)で確認してください。
