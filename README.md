# 経産省関係の調達（委託を含む）・補助金情報

公開サイト: https://yagiharuka.github.io/meti-funding-watch/

経産省関係の公表資料を、**GビズINFOと行政事業レビューの2つの主系列**で検索する非公式索引です。機関公表資料は主系列ではなく、GビズINFO掲載値との照合を実施した範囲だけを「照合の記録」として示します。

> **非公式サイトです。** 経済産業省、GビズINFOその他の公表元が運営するサイトではありません。現在は運用・訂正体制を整備中のため、検索エンジンには掲載しない設定です。

- GビズINFOに掲載された経済産業省関係機関の「調達」（委託を含む）・「補助金」の掲載行
- 行政事業レビュー公式CSVの事業・予算執行・支出先・公開支出経路
- 中部経済産業局の機関公表資料とGビズINFO掲載値を比較した50件の照合記録

主に保証するのは、原資料がどこにあり、どの掲載行を検索または照合対象にしたかです。全支出・実支払を示すものではなく、系列間の金額は合算しません。

## GビズINFO掲載行

GビズINFO掲載行は、公表組織が次のいずれかに該当するものを対象にしています。

- 経済産業省（地方経済産業局を含む）
- 資源エネルギー庁
- 中小企業庁
- 特許庁
- 情報処理推進機構（IPA）
- 新エネルギー・産業技術総合開発機構（NEDO）

法人等の名称（全件CSVの「商号または名称」）と13桁の法人番号で検索できます。各府省庁から提供され、法人番号が付与されてGビズINFOに掲載された情報だけが対象であり、網羅性や支払実績を示すものではありません。

## 機関公表資料との照合

別タブの「照合の記録」では、中部経済産業局の令和4年度上期資料について、掲載順先頭50行とGビズINFO掲載値を比較した結果を示します。分母は照合を試みた50件です。各件から原典PDFとGビズINFO掲載行へ移動できます。2019〜2026年度の機関×年度表では、この標本だけを「一部照合」、残る95セルを「未照合」と明示します。この表示範囲は母集団を意味しません。金額の合計は表示しません。

機関公表資料のparserと既存取得データは、手動照合と履歴確認のため保持します。定期取得せず、公開成果物にも検索用全件データとして同梱しません。沖縄総合事務局は収録・照合の対象外で、過去に取得したデータだけを履歴として保持します。

## 行政事業レビュー

`/review/` では、行政事業レビューの公式CSVから取得済みの経済産業省の事業・予算執行・支出先・公開支出経路を検索します。GビズINFOとは意味が異なるため、別データ・別画面・別更新workflowとして管理し、相互に合算しません。

- 支出先の金額は公式CSVの「支出先の合計支出額」掲載値です。契約額・交付決定額・実支払額と同一視しません。
- 上流・中間・終端の支出先が同じ資金経路に現れる場合があるため、レビュー内でも階層を跨いで足し上げません。
- 未収録年度、移行年度の詳細欠落、レビューシート自体の非掲載があるため、検索0件を「資金を受けていない」と解釈しません。
- 2026-08-15時点ではRSシステムの直接CSV配布経路変更を検知しているため、2026-08-06に公式CSVから取得できていた2024・2025年度の最終検証済みキャッシュを保持しています。新しい値を推測補完していません。
- `.github/workflows/update-review-data.yml` はGビズINFOとは独立して更新を試行し、取得に成功した場合のみreview dataを置き換えます。

## 表示値の意味

- 調達の金額はGビズINFOの「落札価格／活動金額」です。単価や売払いが含まれる場合があります。
- 補助金の金額はGビズINFOの「活動金額」です。法人詳細画面には手続ステータス欄がありますが、全件CSVとREST APIにはその項目がないため、当サイトにはステータスを表示せず、いずれの金額とも自動判定しません。
- そのため金額は足し上げず、掲載行ごとに表示します。
- `0円`、負数、空欄を別々に保持します。空欄だけを「金額の記載なし」と表示します。
- 年度は認定日または受注日の4月始まりで当サイトが算出します。日付がない行は「年度不明」です。
- 認証済みREST API v2でも、全件CSVで証明日が空欄の検査対象は認定日が `null` でした。追加取得できる6メタデータは全件CSVに既に存在するため、年度をAPIで推測補完しません。詳細は[`docs/GBIZ_SUBSIDY_API_AUDIT.md`](docs/GBIZ_SUBSIDY_API_AUDIT.md)に記録しています。
- 公表組織から上流の資金経路はGビズINFOの項目から判定できないため、推定経路は作成しません。

## 自動更新

外部データの取得と公開は分離しています。

- `.github/workflows/refresh-official-data.yml`：手動実行時だけ機関公表資料を取得
- `.github/workflows/discover-official-sources.yml`：手動実行時だけ新規URL候補を監査
- `.github/workflows/refresh-gbiz-data.yml`：週1回、GビズINFO系列だけを更新
- `.github/workflows/update-review-data.yml`：週1回、行政事業レビュー系列だけを更新
- `.github/workflows/update-data.yml`：コードまたは検証済みデータの変更時に、外部サイトへアクセスせず主系列と照合画面を検証してPagesへ公開
- `.github/workflows/ci.yml`：Pull Requestで固定フィクスチャによるlint・build・testだけを実行（外部データは取得しない）

主系列の更新workflowは自系列のデータだけをcommitします。そのbot commitを公開workflowが受け取り、GビズINFOと行政事業レビューの成果物および照合画面を検証してGitHub Pagesへ公開します。一方の系列の取得失敗で、他系列の検証済みデータを破棄しません。

新URL・新年度・新機関の自動探索は行いません。機関公表資料の取得とURL探索は、明示的な手動実行だけに限定します。

全件CSVの対象行と取込行が1行でも一致しない場合は公開しません。公式ダッシュボードと全件CSVは更新時点や集計条件が異なる可能性があるため、両者の差は「取込漏れ」とせず別に表示します。

Repository secret `GBIZINFO_API_TOKEN` がない場合や取得に失敗した場合は、前回の明細と最終取込日時を保持し、状態を「要確認」にします。公式画面の確認時刻だけで明細の鮮度を更新することはありません。

データ更新で安全検査に失敗した場合、新しい候補データはcommitしません。画面修正を含む `main` へのpushでは外部データを再取得せず、直前の検証済みデータに対して全テストを通した画面だけを公開します。候補データで前回キーの欠落・内容変更、区分別件数差の拡大、異常な急増、未承認の公表組織名を検出した場合、新しい明細へは置き換えません。

公開用GビズINFOデータは年度別の `commitments-*.json` とmanifestです。行政事業レビューは独立した `data/review-cache/` から検証済みファイルだけを公開します。機関公表資料の全件データはリポジトリ内に保持しますが、公開検索データには含めません。

## ローカル実行

Node.js 22.13以上が必要です。

```bash
npm ci
npm run update:official
npm run update:review
npm run update:data
npm test
npm run dev
```

行政事業レビューのZIP展開からCSV解析、経路構築、行数会計、manifest生成までを、外部通信なしで固定フィクスチャから再現できます。

```bash
npm run update:review:fixture
node --test tests/review-offline-pipeline.test.mjs
```

## 訂正・確認、利用条件

- 掲載内容の転記・解析・表示に関する確認は、[訂正・確認フォーム](https://github.com/yagiharuka/meti-funding-watch/issues/new?template=correction.yml)で受け付けます。個人情報や未公表情報は記載しないでください。
- 対応原則と履歴は [`CORRECTIONS.md`](CORRECTIONS.md) に記録します。
- コードと再構成データの現在の扱いは [`DATA_AND_CODE_USE.md`](DATA_AND_CODE_USE.md) を参照してください。原資料ごとの利用条件を確認するまで、便宜的に単一のライセンスを付与しません。

公開情報を再構成したもので、経済産業省およびGビズINFOの公式サイトではありません。原データの定義・免責事項は[GビズINFO](https://info.gbiz.go.jp/)で確認してください。
