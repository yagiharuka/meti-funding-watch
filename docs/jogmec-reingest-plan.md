# JOGMEC公式資料 再収録仕様

更新日: 2026-08-26

## 目的

JOGMECについて、疎通確認用の手置き行や単一資料を「収録済み」と扱わず、公式サイトで現在確認できる契約結果・採択結果等の入口を棚卸しし、受取先と金額の意味を検証できる公表行を再収録する。

## 対象候補

- JOGMEC本体の競争入札・落札・契約結果
- JOGMEC本体の随意契約結果
- 補助・助成・公募採択結果のうち、受取先と個別金額または金額段階を公表しているもの
- 現在の公式サイトから到達できる過年度資料

## 対象外

- 募集中の入札・公募だけで結果がないもの
- 受取先を特定できない事業総額
- 共同実施者ごとの配分が不明な総額を個社額へ割り当てること
- JOGMEC以外の機関が公表した二次情報

## 完了条件

1. 公式サイトの取得入口を棚卸しする。
2. 発見資料数・取得成功数・解析成功数・収録行数を記録する。
3. 各資料の掲載行数を、収録行・金額非公表等・明示的除外行へ分解する。
4. 金額非公表・単価・複数社合計を0円や個社額に変換しない。
5. 未解析資料・未説明行が残る場合は `collectionStatus: partial` とする。
6. 既存の検証済み行を後退させない。
7. 専用データ、公式補足索引、企業検索用公式資料索引の件数を一致させる。
8. 全テスト、GitHub Pages公開、公開後live検証まで成功した時点で完了とする。

## 最初の作業

既存parserに埋め込まれた公式URLと、JOGMEC公式サイト内の「契約・入札・公募結果」に関係するリンクを幅優先で探索し、資料台帳を作成する。資料形式と公表単位を分類してから本番parserを設計する。
