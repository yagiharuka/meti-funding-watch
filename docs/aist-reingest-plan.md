# 産業技術総合研究所（産総研）公式資料 再収録仕様

更新日: 2026-08-26

## 対象

産業技術総合研究所が公式サイトで公表している、企業・法人への契約結果または落札結果を確認できる資料を対象とする。

- 産総研本体の公表資料のみ
- 契約相手方、契約日または落札決定日、金額を公表資料上で確認できる行
- 競争契約、随意契約、落札結果を、原資料の区分を保ったまま収録
- 募集中の公告、調達予定、仕様書だけの資料は対象外
- 公表資料に金額がない行は0円へ変換しない
- 複数社連名や契約総額と個社配分を分離できない行は、個社額として収録しない

## 現行実装の問題

現在の産総研公式補足は、特定の公表資料から確認できた少数行だけである。1資料・数行を取得できたことをもって、産総研の公式資料を収録したとは扱わない。

## 再収録手順

1. 現行parserが参照する公式入口と、その周辺の年度別・契約類型別ページを棚卸しする。
2. 公開されている全資料について、URL、年度、契約類型、ファイル形式、更新日を台帳化する。
3. HTML、PDF、表計算ファイルを形式別に分類する。
4. 各資料について、掲載行数を次の区分に完全分解する。
   - 金額を確認でき、収録した行
   - 金額非公表・空欄・記号表示の行
   - 単価等で契約総額ではない行
   - 複数社連名等で個社額を確定できない行
   - 明示的な対象外行
5. 未取得資料、未解析資料、未説明行が1件でもあれば `collectionStatus: partial` とする。
6. 既存の検証済み行を後退させない。

## 完了判定

次をすべて満たした場合だけ、産総研について現在公表されている対象範囲を `complete` とする。

- 公式入口から到達できる対象資料をすべて台帳化
- 全資料を取得・形式分類
- 全掲載行の会計が成立
- 金額非公表等を0円へ変換していない
- parser、索引、画面、公開成果物の全テストが成功
- GitHub Pages公開後に、公開サイトから同一コミットを読み戻して検証
