# 中小企業基盤整備機構・本部 契約情報 再収録仕様

更新日: 2026-08-25

## 対象

中小企業基盤整備機構の公式「契約情報（本部）」だけを対象とする。

- 地域本部は対象外
- 中小企業大学校は対象外
- 調達見通し・募集中の入札情報は対象外
- 本部の契約結果として公開されている「競争入札契約」と「随意契約」を対象とする

公式入口:
https://www.smrj.go.jp/procurement/bid/contract/hq.html

## 現行実装との差

`scripts/smrj-official-supplement.mjs` は現状、`MIN_FISCAL_YEAR = 2026` かつ一覧正規表現が `令和N年N月競争入札契約` に限定されている。このため、実質的に「2026年度以降の本部競争入札」だけを取得している。

再収録では以下を満たすまで `complete` と扱わない。

1. 公式入口に現在掲載されている全年度を資料台帳へ登録する。
2. 競争入札・随意契約の両系列を登録する。
3. 月次PDFと旧年度の年度一括PDFを形式別に解析する。
4. 各PDFについて、掲載行数 = 金額あり収録行 + 金額非公表/金額なし行 + 明示的除外行、を成立させる。
5. 未解析PDF・未説明行が1件でもあれば `collectionStatus: partial` とする。
6. 金額非公表・記号表示を0円に変換しない。
7. 既存の検証済みレコードは後退させない。

## 完了判定

「1資料取得できた」「1行解析できた」では完了としない。

本部公式ページに現在掲載されている対象資料について、取得・形式分類・行数会計がすべて完了した場合だけ、本部契約情報の現在公開範囲について `complete` と判定する。
