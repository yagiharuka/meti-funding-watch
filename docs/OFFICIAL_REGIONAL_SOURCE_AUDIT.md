# 地方経済産業局・公式資料の取込監査

最終確認日: 2026-08-13

## 結論

中国経済産業局・北海道経済産業局・四国経済産業局について、公式目次から直接リンクされる機械処理可能な HTML/XLSX を146資料定義として列挙した。定義URLは、保存した6つの公式目次の `href` と146/146件で完全一致する。加えて、東北経済産業局の令和7年度交付決定2資料・契約18資料（345行）、関東経済産業局の保存済み公式PDF 24資料・590掲載行、中部経済産業局の令和6年度交付決定2資料・契約4資料（500行）、近畿・九州経済産業局の令和7年度交付決定各2資料（264行・309行）、競争入札（委託費）12資料（21行・8行）、近畿局の随意契約（委託費）6資料40行をstrict parserへ接続した。関東局の令和4～6年度契約12資料・219行は年度途中の保存スナップショットであり、年度全体の完全収録とは扱わない。

ただし、短時間の連続取得では各局サイトが HTTP 202 の AWS WAF challenge またはCloudFront 403を返す。HTML/XLSXは、公式URLから直接検証した20資料に加え、同じ公式原本URLを保持する固定WARP captureで検証した111資料を `REGIONAL_OFFICIAL_DOCUMENTS` として接続した。合計131資料・初回検証2,917行で、残る15資料は `REGIONAL_CANDIDATE_DOCUMENTS` として分離する。PDFは東北20資料・関東24資料・中部6資料・近畿16資料・九州6資料だけを資料別receipt付きで接続する。いずれも、段階導入を地方局・全年度・全公表区分の「網羅」とは表示しない。

## 実ファイルで通過した監査

WAFがchallengeへ切り替わる前に公式URLから直接取得できた20資料・554行をstrict parseし、`data/official-regional-evidence-map.json` に資料ID・原本URL・bytes・SHA-256・rowCountを固定した。

- 中国局: 4 XLSX・204行（FY2020/FY2024競争・物品役務等、FY2025交付決定上期・下期）
- 北海道局: 8 HTML・213行（FY2023契約4区分、FY2024競争2区分、FY2025競争物品、FY2025交付決定）
- 四国局: 8 HTML・137行（FY2024–FY2026の契約各区分、FY2025交付決定上期）

この554行は初回検証時のevidence件数である。ライブ資料の更新で行が追加されうるため、公開件数は毎回のmanifestを正とする。

残る126候補を、公式目次に実在する原本URLのままWARP固定capture `20260602/20260601000000` からFull GETし、同じstrict parserで一括照合した。形式差を資料単位で再監査した16資料を含む111資料・2,363行が通過し、`data/official-regional-archive-evidence-map.json` に原本URL・保存URL・公式入口・bytes・SHA-256・rowCountを固定した。内訳は次のとおり。

- 中国局: 30 XLSX・1,208行（契約23資料314行、交付決定7資料894行）
- 北海道局: 8 HTML・427行（契約5資料34行、交付決定3資料393行）
- 四国局: 73 HTML・728行（契約62資料207行、交付決定11資料521行）

したがって直接取得分と固定WARP分の合計は、中国局34資料1,412行、北海道局16資料640行、四国局81資料865行である。WARP資料は保存応答のbytes・SHA・行数の完全一致を毎回要求し、取得不能時の継続使用も前回manifest・資料定義・行集合が一致する場合だけ許可する。111資料は初回固定原本を毎日再利用せず、通常更新ではWARP URLを再取得する。

安全停止した15資料は、中国局7資料（404、日付を「－」と掲載した交付決定の実データ行）、北海道局5資料（FY2026の404が4資料、FY2024随意委託の年度外掲載日が1資料）、四国局3資料（FY2026の404）である。中国局FY2020年7～9月の交付決定は、事業名・交付先・0円の掲載値を持つ実データ行の交付決定日が「－」であり、注記行として除外せず資料全体を未収録とした。北海道FY2024随意委託は14行中1行が公式原本上「2023年4月30日」と掲載されており、FY2024資料へ帰属させる根拠が一致しないため、推測訂正も当該行の除外もせず資料全体を未収録とした。資料ID・原本URL・保存URL・失敗理由は `data/official-regional-gap-inventory.json` に固定した。

今回接続した形式差8資料は、北海道の12列公共工事1資料、16列随意契約3資料、四国の15列競争契約1資料、複合日付2資料、Excel通し番号日付1資料である。複合日付は同じ公式行に明示された「購入」「保守」の日付から、月別資料の対象月に一致する日付だけを資料ID・完全一致raw値に限定して検索日付へ採用し、raw値はそのまま保持する。Excel通し番号は当該1資料に限って1900日付系として変換し、通常の日付文字列や他資料には適用しない。

中国局の交付決定5資料・733行では、一般会計・エネルギー対策特別会計・特許特別会計の表を連結した原本に、会計区分見出しと単位行が途中挿入される。これらは資料ID・シート名・行番号・セル列・完全一致値を固定した46行だけを非明細行として扱い、値や位置が変われば安全停止する。明細の日付・金額・交付先は補正していない。

中国局の公共工事3資料・3行は、公式見出しの「商号または名称」と、FY2023随意契約資料の「規格競争または公募」を資料ID限定aliasとして追加した。一般の契約表へaliasを広げず、FY2023の行に掲載された契約方式「少額随契」をraw値として保持する。3原本はbytes・SHA-256・1行ずつのstrict parse結果を個別に固定した。

## Fail-closed 条件

候補パーサーは次を満たさない資料を公開行に変換しない。

- UTF-8/Shift_JIS の明示と厳密復号
- HTML文書シグネチャとWAF/エラーページ除外
- 執行機関・年度・契約区分を示す見出し
- 資料ごとに固定した列数、列位置、必須見出し
- `rowspan`/`colspan` を解決した後の内部欠損なし
- 事業名、相手方、日付、掲載額文字列の必須値
- 契約日/交付決定日が資料の年度内（月別資料は対象月内）
- 公式原本URLを用いた安定ID（保存・配信URLへの変更でIDを変えない）
- PDFについては、原本bytes/SHA-256、ページ寸法・ページ数、位置付き文字要素数、ページ別行数、掲載番号範囲の完全一致

## 意味上の境界

この系列は公式資料に掲載された「契約金額欄の掲載値」と「交付決定額欄の掲載値」であり、GビズINFO系列とは合算しない。実支払、額の確定、返納、再委託・下請、基金や所管法人からの下流支出、間接補助先・最終受益者は網羅しない。

## 残る15候補の公開ゲート

次を完了するまで残る15候補を本番取込へ接続しない。

1. 候補ごとのFull GETとSHA-256・bytes receiptの保存
2. 候補ごとのstrict parseと資料別行数receipt
3. WAF challenge時に更新時間を長大化させない、間隔・再試行・前回検証済み資料継続の設計
4. 初回候補行の重複、年度、法人番号、金額raw/null、ID集合の全件検証
5. FY2026年度途中と、目次にリンクのない年度・月をUIで明示
